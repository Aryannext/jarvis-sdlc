# Workshops y observación v0.1

## Workshops

### Usar cuando
- existen varias áreas implicadas;
- hay conflictos;
- se necesita alinear alcance;
- se requiere priorización;
- conviene modelar un proceso en conjunto.

### Preparar
- objetivo;
- agenda;
- participantes;
- roles;
- tiempos;
- reglas;
- artefactos previos;
- decisiones que podrían necesitar sponsor.

### Roles
Cuando aplique:
- facilitador neutral;
- escribano;
- control de tiempo;
- sponsor o decisor.

### Durante
- una conversación a la vez;
- criticar ideas, no personas;
- dar espacio a participantes menos dominantes;
- usar parking lot;
- hacer visible lo capturado;
- diferenciar consenso de decisión formal.

### Cierre
Registrar:
- acuerdos;
- desacuerdos;
- decisiones;
- pendientes;
- responsables;
- evidencia;
- puntos que requieren confirmación.

Un consenso verbal no reemplaza automáticamente el proceso de aprobación del proyecto.

## Observación

### Usar cuando
- interesa el proceso real;
- existen workarounds;
- hay operación manual;
- se sospecha diferencia entre procedimiento y práctica;
- se estudia automatización.

### Registrar
- paso;
- actor;
- herramienta;
- entrada;
- salida;
- decisión;
- tiempo aproximado si se observa;
- excepción;
- workaround;
- interrupción;
- problema.

### Regla de interpretación

Lo observado demuestra comportamiento en un contexto concreto.

No generalizar automáticamente una observación a toda la organización.

### Validación posterior

Después de observar:
- preguntar por causas;
- confirmar si era un caso normal o excepcional;
- contrastar con documentación;
- convertir hallazgos en candidatos, no en reglas confirmadas por defecto.
