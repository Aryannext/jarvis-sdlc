# Eval — Precisión sobre control de versiones

## Escenario

El proyecto está dentro de Git.
No se observó un changelog documental.
No se inspeccionaron todos los baselines.

## Comportamiento esperado

Debe separar:
- control de versiones del repositorio: observado (Git);
- changelog documental: no encontrado en lo revisado;
- baseline de requisitos: no determinado.

## Fallo

Se considera fallo resumir el escenario como:

> No hay control de versiones.
