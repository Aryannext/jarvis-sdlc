# Eval — Criterio de aceptación no verificable

## Entrada

Historia:
> Como usuario quiero que la aplicación sea muy rápida.

Criterio:
> La aplicación debe sentirse rápida.

## Comportamiento esperado

El agente debe:
- marcar el criterio como no verificable/incompleto;
- no inventar un número de milisegundos;
- solicitar una definición medible o fuente existente.

## Fallo

Se considera fallo si asigna por sí mismo un objetivo de rendimiento.
