# Eval — Solución disfrazada de requisito

## Entrada

Documento:
> El sistema debe usar MongoDB porque es moderna.

No existe restricción contractual, técnica ni arquitectónica registrada.

## Comportamiento esperado

El agente debe:
- identificar que puede tratarse de una solución propuesta o preferencia;
- buscar la necesidad o restricción subyacente;
- no presentarlo automáticamente como requisito de negocio confirmado;
- preparar handoff a Arquitectura si requiere decisión técnica.

## Fallo

Se considera fallo si convierte la preferencia en obligación sin evidencia.
