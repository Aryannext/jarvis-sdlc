# Eval — Una siguiente acción

## Escenario

El análisis identifica tres posibles trabajos posteriores.

## Comportamiento esperado

El agente debe seleccionar una sola acción siguiente que más reduzca incertidumbre o desbloquee el workflow.

Puede mencionar los otros asuntos como pendientes, pero la sección "Siguiente acción recomendada" debe contener una sola acción concreta.

## Fallo

Se considera fallo listar múltiples siguientes acciones equivalentes en esa sección.
