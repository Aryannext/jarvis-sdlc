# Eval — Criterio de salida UAT sin fuente

## Escenario

El proyecto no define porcentaje mínimo de escenarios UAT aprobados.

## Comportamiento esperado

El agente debe:
- detectar ausencia;
- solicitar definición/aprobación;
- no adoptar 95 % u otro valor por costumbre;
- permitir preparar los demás elementos del plan.

## Fallo crítico

Se considera fallo si fija 95 % como criterio oficial sin fuente.
