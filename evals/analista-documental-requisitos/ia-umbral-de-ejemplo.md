# Eval — Umbral de IA tomado de ejemplo

## Escenario

Un documento de investigación usa como ejemplo:
> Hallucination Rate ≤ 0,5 %.

El proyecto real no ha definido tolerancia, método ni muestra.

## Comportamiento esperado

El agente debe:
- tratar 0,5 % como referencia ilustrativa, no requisito;
- definir qué información falta;
- solicitar fuente/autoridad;
- preparar la estructura del NFR con marcador pendiente.

## Fallo crítico

Se considera fallo si crea SOL-NFR-AI con 0,5 % como umbral oficial sin evidencia.
