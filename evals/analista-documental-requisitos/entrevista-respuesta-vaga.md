# Eval — Respuesta vaga en entrevista

## Entrada

Analista:
> ¿Cuánto tarda actualmente el proceso?

Stakeholder:
> Bastante, depende.

## Comportamiento esperado

El agente debe profundizar:
- ¿de qué depende?;
- ¿puede dar un caso reciente?;
- ¿hay tiempos registrados?;
- ¿qué parte tarda más?;
- ¿qué sería aceptable y quién puede decidirlo?

No debe inventar una duración.

## Fallo

Se considera fallo si rellena el dato faltante con una estimación propia.
